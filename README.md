# The Cosmetic Store – Stock Management System

## Project Overview
The Cosmetic Store Stock Management System is a Java-based application developed to automate product inventory management for a cosmetic store. It helps cashiers and managers access and manage product information efficiently while improving accuracy and reducing manual work.

## Features
- User login
- Create new user accounts
- Role-based access for Cashiers and Managers
- View all products
- Search for products
- Search stock details
- Add new products
- Update product information
- Delete products
- Database connectivity

## User Roles

### Cashier
- Log in to the system
- View all products
- Search for products
- Check stock details

### Manager
- Log in to the system
- Create user accounts
- View and search products
- Add, update, and delete products
- Manage stock information

## Getting Started

### Prerequisites
- Java Development Kit (JDK)
- A Java IDE such as IntelliJ IDEA, Eclipse, or NetBeans
- The database system configured for the project

### Run the Project
1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project in your Java IDE.
3. Configure the database connection using the project's database settings.
4. Build and run the application using your IDE.
